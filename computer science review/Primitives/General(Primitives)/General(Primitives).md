# General(Primitives)

## Boolean
- true or false
- Some languages (e.g., C) treat 0 as false
  - Not Java

## Floating-Point Number
- `float`
  - Faster
  - Best for large quantities of floating-point numbers
  - Uses scientific notation in base 2
- `double`
  - More precise
  - Use by default
- `long double`
  - For higher range/accuracy than double
- `real`

## Character
- a basic unit of information that represents a letter, number, symbol
- ASCII (American Standard Code for Information Interchange) is the most common character encoding format for text data in computers and on the internet
  - In standard ASCII-encoded data, there are unique values for 128 alphabetic, numeric or special additional characters and control codes
  - The letter "A" is 65, "B" is 66, "a" is 97, "b" is 98, and the number "1" is 49
