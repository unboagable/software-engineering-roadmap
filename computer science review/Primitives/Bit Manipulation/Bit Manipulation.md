# Bit Manipulation

## Basics
- AND `&`: `1 & 1 = 1` (otherwise 0)
- OR `|`: `1 | 0 = 1`, `0 | 1 = 1`, `1 | 1 = 1`
- XOR `^`: `1 ^ 0 = 1`, `0 ^ 1 = 1`, `1 ^ 1 = 0`

## Shifts
- **Left Shift**: `00011001 << 2 = 01100100`, `00011001 << 4 = 10010000`
- **Right Shift**:
  - Arithmetic shift (sticky sign bit): `00011001 >> 2 = 00000110`
  - Logical shift: `00011001 >> 4 = 00000001`
